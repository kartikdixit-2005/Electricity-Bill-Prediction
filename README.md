# ⚡ Electricity Bill Prediction Using Machine Learning

## 📌 Project Overview
This project predicts electricity bills using **Multiple Linear Regression**, a supervised machine learning algorithm. It uses monthly usage hours and tariff rate to estimate the electricity bill.

## 🚀 Live Demo
[Click here to try the Electricity Bill Prediction App](https://electricity-bill-prediction-lfmxx4jmhu4y3xd4ctjx2a.streamlit.app/)
## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Jupyter Notebook
- Google Colab

## 📊 Features
- Predicts electricity bills using machine learning.
- Takes monthly usage hours and tariff rate as input.
- Displays the predicted electricity bill.
- Provides a preview of the dataset.
- Shows model evaluation information.

## 🧠 Algorithm
**Multiple Linear Regression**

**Input Features:**
- MonthlyHours
- TariffRate

**Target Variable:**
- ElectricityBill

## ▶️ Run Locally
1. Clone this repository:
   `git clone https://github.com/kartikdixit-2005/Electricity-Bill-Prediction.git`

2. Open the project folder:
   `cd Electricity-Bill-Prediction`

3. Install the required libraries:
   `pip install -r requirements.txt`

4. Run the Streamlit app:
   `streamlit run app.py`
